
# Python 数据处理与多模态智能客服项目
本项目以数据预处理、清洗、批量结构化处理为核心，在此基础上实现RAG知识库与多模态问答能力，适配数据挖掘、数据处理类岗位需求。

## 核心模块（岗位匹配重点）
1. refine_knowledge_base.py：前置数据预处理、文本清洗、脏数据过滤、多格式文档解析（PDF/Word/TXT）、数据标准化
2. batch_process.py：批量自动化数据处理、异常捕获、日志记录、JSON转CSV结构化输出
3. api_server2.py：接口服务、数据检索、RAG知识库调用、多模态问答
4. 配套：技术文档、项目PPT、依赖配置

## 技术栈
Python | PyMuPDF | python‑docx | CSV/JSON | vector-store | 大模型API

## 核心能力
- 原始数据前置预处理、清洗、去重、格式规范化
- 多源文档批量解析与结构化
- 自动化脚本开发、数据导出
- AI辅助数据检索与应用（加分项）
